# Neon Drift

A dependency-free browser arcade survival game. Pilot the luminous ship, dodge falling hazards, collect energy shards, and chase a higher best score.

## Run

Open `index.html` in any modern browser. No build step, server, package manager, or external assets are required.

## Controls

Use Left/Right Arrow or A/D on desktop. On touch devices, use the on-screen buttons or swipe across the game field.
